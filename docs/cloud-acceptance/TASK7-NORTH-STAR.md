# Task 7 North Star

This task proves IncidentLens as a real cloud-incident Agent Harness, not as a
synthetic context-compaction benchmark.

## Required outcome

1. Run the normal IncidentLens entry point with the configured real DeepSeek
   model and its normal context settings.
2. Use the registered Tencent CVM target through the real SSH transport.
3. Let the model choose its investigation path across host, container, logs,
   source, compose and configuration. Read-only shell/container inspection is
   allowed; cloud mutations and restarts require exact approval.
4. Find the controlled incident's real independent fault paths from evidence.
5. Propose and apply the minimal repair, then prove the four request-matrix
   cells return 201.
6. Roll back in the same recorded task, reproduce the faulty matrix, reapply
   the correct repair and prove all four cells return 201 again.
7. Redact secrets, personal paths and unnecessary host identifiers; publish
   hashes, evaluator results and an honest README record.

## Context and memory rule

Context compaction is supporting infrastructure, not the acceptance target.
Never shrink the configured model window merely to force compaction. If
compaction occurs naturally, record whether objective, constraints, Todo,
evidence and safety state survive. Otherwise rely on local compaction tests and
make no real-run compaction claim.

Project Memory remains local, project-scoped and evidence-backed. It must not
require human approval and must never replace evidence needed for the current
investigation.

## Stop conditions

Do not publish a run that is scripted, budget-paused, waiting for an unrelated
approval, incomplete, or dependent on fabricated metrics. Fix real defects
exposed by the run, start from a clean controlled baseline, and record the best
complete rerun.
